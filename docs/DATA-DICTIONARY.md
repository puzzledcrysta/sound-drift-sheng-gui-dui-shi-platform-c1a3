# 声轨对时台数据字典

## 来源文件

| 字段 | 定义 |
|---|---|
| 声轨片段 | 文本主键，保留前导零。跨业务键不汇并记录。 |
| 修订号 | 正整数。最高版优先；最高同版字段冲突或存在同版、更新版的未采信记录时隔离，旧版无法接替。 |
| 提交时间 | ISO 8601，必须带 UTC 偏移量。标准化后展示 UTC。 |
| 原始备注 | 可空，允许引号内换行。 |
| 采样率赫兹、允许漂移ppm、锚点、片段始样本、片段末样本 | 必填字段。多项字段用半角分号隔开，显式空集合用 `无`。 |
| 跨日记录 | 可空。跨夜录音参考钟归零的旁证。半角分号分隔，每项为样本号 `48000`、日期 `2026-11-19` 或二者 `48000:2026-11-19`；`无` 表示没有旁证。 |

识别 `UTF-8`、UTF-8 BOM 与独立的 `GB18030` 文件。`业务编号`、`版本`、`更新时刻`、`备注` 为旧版表头别名。新旧名同时出现会被拒绝。`-`、`N/A`、`NULL`、`未知` 和空串均按必填值缺失处理。物理行号指 CSV 逻辑记录起始行。

## 计算字段

锚点为 `样本编号:参考毫秒`，按整数样本号排序。校准时间由包住片段的锚点线性求值。

每段都验证单调与最大漂移。跨锚段切开计算时长，保留绝对样本号的整数精度。

跨夜录音常在零点后出现参考钟归零，钟面读秒回退并非故障。`跨日记录` 提供只要一处钟面回退的直接旁证：

- 样本号定位回退所在的锚段；该位置确无回退时报 `SOUND_WRAP`，回退发生在别处则原样报 `SOUND_REWIND`。
- 日期是设备记录，只要求与观测到的回退一一配对；无样本号的日期按先后顺序配给尚未解释的回退，多余时拒收。
- 有旁证的回退在计算时补 +1 日，其余各项校验照旧；漂移仍按回退后的斜率计算。
- 没有旁证的回退仍按 `SOUND_REWIND` 隔离，不会因为同批别处有跨日记录而被顺带放行。

放行以片段为单位：被规则采信的片段放行出证，无旁证的回退单独留在隔离。同一组输入字节与规则版本生成同一条放行结论，重复运行不新增版本；结论写入失败时保留上一版。

数值在服务端以十进制定点方式计算，对外按字符串传输。单文件上限 128 KiB，复合字段最多 240 个项目，个别字段还有业务上限。格式无法恢复的 CSV 整批拒绝，列数、缺字段、来源冲突和业务条件错误逐条隔离。

## 复算与外部清单

外部清单包含 `声轨片段` 和 `外部记录值(毫秒)`，允许省略不在对账范围内的键。同一键重复会拒绝该清单。结果数值单位为 **毫秒**。差值按本次复算减外部记录，缺一侧时差值计算以 0 占位并保留缺失原因。

同一对输入字节与规则版本生成同一批次，导出包含两个文件摘要、证据行、单边差异和复核修订记录。复核保存前检查当前版本，在有隔离、差异或退回时必须填写意见。
